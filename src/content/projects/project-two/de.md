Ergänzen Sie einen zweiten Absatz mit mehr Kontext: für wen das Projekt gedacht ist, warum Sie es entwickelt haben und was es interessant macht. Sie können **wichtige Begriffe** hervorheben und Code wie `npm run build` erwähnen.

## Ziel

Beschreiben Sie das Hauptziel des Projekts in einem einzigen Satz.

- **Problem:** Erläutern Sie das Problem, das Sie lösen wollten.
- **Zielgruppe:** Geben Sie an, wer von der Lösung profitiert.
- **Einschränkung:** Nennen Sie Vorgaben oder Grenzen, innerhalb derer Sie arbeiten mussten.
