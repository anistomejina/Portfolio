## Overview

A robust, hosted e-commerce web application built by a team of three on AWS.

## My role

I designed and developed the entire cloud architecture that hosts the web application.

## Architecture

- **Hosting:** Amazon S3.
- **Delivery:** Amazon CloudFront as the CDN.
- **DNS:** Amazon Route 53.
- **TLS:** AWS Certificate Manager for HTTPS.

## Stack

`AWS S3` · `Route 53` · `CloudFront` · `AWS Certificate Manager`
